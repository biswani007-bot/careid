## 3. Multi-Page PDF Import Architecture

### 3.1 Preserving Page Order & Binary Byte Integrity

A PDF document (such as a multi-page pathology report or CBC panel) structures its pages hierarchically inside its internal xref table and catalog dictionary:
```
Root -> /Pages -> /Kids [Page1_Ref, Page2_Ref, Page3_Ref...] -> /Count N
```
- **Architectural Decision**: Under NO circumstances should the client decompose, re-rasterize, or split the multi-page PDF into separate images before uploading.
- **Byte Stream Transmission**: The native `File` object retrieved from the file input is streamed as a single binary payload via `multipart/form-data` (`FormData.append('file', file, file.name)`).
- **Invariance Guarantee**: By transmitting the unaltered byte buffer directly to `POST /api/v1/attachments`:
  1. The page order remains 100% deterministic and preserved as generated by the laboratory or imaging facility.
  2. The byte length reported by the backend (`fileSize`) matches `file.size` bit-for-bit (validating `TC-F05-02`).
  3. The MIME type is preserved as `application/pdf` (`TC-F05-04`).
  4. The original filename is preserved in `originalName` (`TC-F05-03`).

### 3.2 Dedicated PDF Import Flow

To provide the cleanest user experience and fulfill Figma node 1:1242 specifications:

## 4. Comprehensive Client-Side Document Validation

### 4.1 Allowed Constraints Matrix

| Parameter | Allowed Values / Rule | Error Message if Violated |
|---|---|---|
| **File Extension** | `.pdf, .jpg, .jpeg, .png, .webp, .tiff, .tif, .dcm, .dicom` | `Unsupported document format. Allowed formats: PDF, PNG, JPG, WEBP, TIFF, DICOM.` |
| **MIME Types** | `application/pdf`, `image/jpeg`, `image/png`, `image/webp`, `image/tiff`, `application/dicom`, `application/octet-stream` | `Invalid MIME type detected for uploaded clinical document.` |
| **Minimum Size** | `file.size > 0` (non-empty) | `The selected file is empty (0 bytes). Please upload a valid document.` |
| **Maximum Size** | `file.size <= 25 * 1024 * 1024` (26,214,400 bytes) | `File size exceeds the 25 MB limit. Please select a smaller file.` |
| **Filename Safety**| Strip path traversal `../` or `..\` | Sanitized to basename before display & upload |

> **Empirical Validation Note (E2E Test Run)**: In master test execution against `https://360api.vnvision.in`, server-side transmission of a 26MB buffer in `TC-B03-02` resulted in a 20-second network latency timeout over the live connection. Client-side short-circuiting in `validateClinicalDocument` is therefore paramount: by preventing oversized files from initiating network requests, the UI avoids prolonged connection saturation and provides instantaneous feedback (<5ms) to the clinician.

### 4.2 Validation Helper Implementation

```typescript
export interface ValidationResult {
  isValid: boolean;
  errorMessage?: string;
  sanitizedName: string;
  detectedFormat: SupportedFileFormat;
}

export const ALLOWED_EXTENSIONS = [
  '.pdf',
  '.jpg',
  '.jpeg',
  '.png',
  '.webp',
  '.tiff',
  '.tif',
  '.dcm',
  '.dicom',
] as const;

export const MAX_DOCUMENT_SIZE_BYTES = 25 * 1024 * 1024; // 25 MB

export function validateClinicalDocument(file: File): ValidationResult {
  const sanitizedName = file.name.replace(/^.*[\\/]/, '').trim() || 'clinical_document.pdf';

  // 1. Check for empty files
  if (file.size === 0) {
    return {
      isValid: false,
      errorMessage: 'The selected file is empty (0 bytes). Please upload a valid document.',
      sanitizedName,
      detectedFormat: 'PDF',
    };
  }

  // 2. Check for oversized files
  if (file.size > MAX_DOCUMENT_SIZE_BYTES) {
    return {
      isValid: false,
      errorMessage: 'File size exceeds the 25 MB clinical threshold. Please upload a smaller file.',
      sanitizedName,
      detectedFormat: 'PDF',
    };
  }

  // 3. Check file extension
  const dotIndex = sanitizedName.lastIndexOf('.');
  const ext = dotIndex !== -1 ? sanitizedName.slice(dotIndex).toLowerCase() : '';

  if (!ALLOWED_EXTENSIONS.includes(ext as (typeof ALLOWED_EXTENSIONS)[number])) {
    return {
      isValid: false,
      errorMessage: 'Unsupported document format. Allowed formats: PDF, PNG, JPG/JPEG, WEBP, TIFF, DICOM.',
      sanitizedName,
      detectedFormat: 'PDF',
    };
  }

  // Map to format chip
  let detectedFormat: SupportedFileFormat = 'PDF';
  if (['.jpg', '.jpeg', '.webp'].includes(ext)) {
    detectedFormat = 'JPG / JPEG';
  } else if (ext === '.png') {
    detectedFormat = 'PNG';
  } else if (['.dcm', '.dicom'].includes(ext)) {
    detectedFormat = 'DICOM';
  }

  return {
    isValid: true,
    sanitizedName,
    detectedFormat,
  };
}
```

### 6.2 Refactored `processSelectedFile` with Live Upload

```typescript
const processSelectedFile = async (file: File) => {
  setUploadError(null);

  // 1. Client-Side Validation
  const validation = validateClinicalDocument(file);
  if (!validation.isValid) {
    setUploadError(validation.errorMessage || 'Invalid document format or size.');
    return;
  }

  // 2. Automatically sync format chip
  setSelectedFormat(validation.detectedFormat);

  // 3. Format file size
  const fileSizeFormatted =
    file.size > 1024 * 1024
      ? `${(file.size / (1024 * 1024)).toFixed(1)} MB`
      : `${Math.round(file.size / 1024)} KB`;

  // 4. Client-side local preview only for images
  const previewUrl = file.type.startsWith('image/') ? URL.createObjectURL(file) : undefined;

  // 5. Set initial uploading state
  setUploadedFile({
    rawFile: file,
    name: validation.sanitizedName,
    size: fileSizeFormatted,
    type: file.type || (validation.detectedFormat === 'PDF' ? 'application/pdf' : 'application/octet-stream'),
    previewUrl,
    isUploading: true,
  });

  // 6. Upload directly to live backend attachment endpoint
  try {
    const uploaded = await attachmentService.uploadAttachment(file, {
      originalName: validation.sanitizedName,
      category: 'LAB_RESULT',
      patientProfileId: patient?.id,
    });

    setUploadedFile((prev) =>
      prev
        ? {
            ...prev,
            attachmentId: uploaded.id,
            storageUrl: uploaded.storageUrl,
            storageKey: uploaded.storageKey,
            isUploading: false,
          }
        : null
    );
  } catch (err: unknown) {
    const msg =
      err instanceof Error
        ? err.message
        : 'Failed to upload document binary to CareID vault. Please try again.';
    setUploadError(msg);
    setUploadedFile(null);
  }
};
```
